<analysis>**original_problem_statement:**
DaViz: Your Web-Based Data Visualization tool with Predictive Analysis
In the modern data-driven world, extracting meaningful insights from data often requires
technical expertise in tools such as SQL, Microsoft Excel, or programming languages, which
creates a barrier for non-technical users. DaViz is proposed as a user-friendly, web-based data
visualization and analytics platform designed to simplify data handling and interpretation
through an intuitive and visually appealing interface. The primary objective of DaViz is to
enable users to store, manage, and visualize data without requiring prior knowledge of databases
or programming.
The system allows users to create and manage datasets through an interactive database interface,
where rows and columns can be added dynamically by simple user input. Data can be stored
securely in a relational database or entered individually through the application interface. Once
the data is collected, DaViz provides multiple visualization options, including pie charts, bar
charts, histograms, and line graphs, allowing users to choose visual representations according to
their analytical needs.
In addition to descriptive visualization, DaViz integrates basic artificial intelligence capabilities
to generate future prediction visualizations based on historical data patterns. Using machine
learning techniques and external AI services such as Open-AI or Google Gemini APIs, the
system analyzes trends and presents predictive graphs to help users understand potential future
outcomes. This feature enhances decision-making by combining data visualization with
predictive analytics.
The proposed system focuses on usability, responsiveness, and scalability, making it suitable for
students, small businesses, and non-technical professionals. By eliminating the complexity of
traditional data analysis tools, DaViz aims to democratize data visualization and make data-
driven insights accessible to a wider audience through an efficient and intelligent web
application.

**what currently exists?**
A fully functional full-stack web application, DaViz. The application allows users to create datasets either by manual entry or by uploading CSV and Excel files. On the main dashboard, users can view and delete their created datasets. The dataset detail page is the core of the application, offering a rich set of features:
- **Data Table**: Displays the raw data of the selected dataset.
- **Data Operations Toolbar**: A feature-rich toolbar that allows users to perform statistical calculations (mean, median, mode, min, max, sum, count), sort data, and group data by a specific column.
- **Visualizations**: 10 different chart types (Bar, Horizontal-Bar, Stacked, Line, Area, Scatter, Radar, Composed, and Pie) to visualize the data.
- **AI Predictions**: Utilizes a GPT-5.2 model to generate future predictions based on historical data. The number of predicted data points matches the number of historical points.
- **Separate Prediction Chart**: A dedicated chart displays only the AI-predicted future values, visually distinct from the historical data chart.
- **Chart Download**: Functionality to download the current chart view as an image.
The application features a fully custom UI, including a user-provided logo, a custom hero image on the landing page, and a vibrant multi-color theme, with all default Emergent branding removed.
